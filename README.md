# Comparing PCA and t-SNE for Handwritten Digit Clustering

## Overview

This project explores how dimensionality reduction affects K-Means clustering of handwritten digit images. It compares clustering on the original data with clustering on representations generated by Principal Component Analysis (PCA) and t-distributed Stochastic Neighbor Embedding (t-SNE).

## Dataset

The project uses the **Digits dataset from scikit-learn**, not the full MNIST dataset. It contains 1,797 handwritten digit images representing digits 0–9. Each image is 8 × 8 pixels and is represented by 64 pixel-intensity features.

## Methods

- **Exploratory Data Analysis (EDA):** Examine class distributions and pixel intensities.
- **Cluster selection:** Explore the Elbow method and Silhouette score.
- **K-Means clustering:** Compare clustering on the original data, PCA-reduced data, and t-SNE embeddings.
- **Evaluation:** Use the Adjusted Rand Index (ARI) to compare predicted clusters with the true digit labels.
- **Perplexity analysis:** Investigate how different t-SNE perplexity values affect clustering results.

## Results

The highest ARI among the tested configurations was achieved by K-Means on the t-SNE embedding with perplexity 15.

| Method | ARI |
|---|---:|
| Original data + K-Means | 0.6669 |
| PCA (2 components) + K-Means | 0.3880 |
| t-SNE (perplexity 15) + K-Means | 0.9010 |

These results suggest that the t-SNE embedding produced clusters that agreed more closely with the true digit labels in this experiment. The results depend on the chosen parameters and do not establish that t-SNE is always the best method for clustering.
